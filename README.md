# RentEase — Rental Marketplace

Phase 1 frontend foundation for the RentEase rental marketplace.

## Tech used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- jQuery
- Font Awesome
- Leaflet.js

## Included

- Responsive navbar
- Hero/search interface
- Location, property type and budget filters
- Property cards
- Favourite buttons with localStorage
- Login modal
- Signup modal
- Client-side validation
- Toast notifications
- Empty state
- How-it-works section
- Leaflet map with demo listings
- About section
- CTA
- Footer
- Responsive mobile layout

## Folder structure

rentease-rental-platform/
├── index.html
├── css/
│   └── style.css

## Run

Open `index.html` in a browser, or use VS Code Live Server.

Backend features will be added in later phases.
